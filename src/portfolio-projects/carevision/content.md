# CareVision
CareVision ist eine vereinfachte Portfolio-Darstellung eines Monitoring-Projekts.

### Ziel
Das Ziel war, Zustände und Warnungen aus einem technischen System übersichtlich darzustellen.

### Mein Beitrag
Ich habe mich vor allem mit Frontend-Struktur, Statusanzeigen und der Integration von Demo-Daten beschäftigt.

### Tech Stack
- React
- TypeScript
- Tailwind
- Vite

### Learnings
- bessere Trennung von UI und Datenzugriff
- saubere Komponentenstruktur
- Demo-fähige Präsentation echter Projekte
